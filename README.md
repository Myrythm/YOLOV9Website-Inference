# Deteksi Rumah Layak/Tidak Layak Huni dengan YOLOV9
## Prasyarat

1. **Python 3.x** harus terpasang di sistem Anda.
2. Pastikan Anda mengunduh dependencies yang diperlukan.

## Instalasi

Ikuti langkah-langkah berikut untuk menyiapkan dan menjalankan proyek ini di lingkungan lokal Anda.

### 1. Buat Virtual Environment

Buat environment virtual menggunakan `venv`:

```bash
python -m venv env
```

### 2. Aktifkan environment:
Windows:
```bash
.\env\Scripts\activate
```
Mac/Linux:
```bash
source env/bin/activate
```
### 3. Install Requirements
```bash
pip install -r requirements.txt
```
### 4. Jalankan Backend (FLask)
```bash
python app.py
```
### 5. Buka Web
Buka file index.html di browser Anda untuk mengakses aplikasi web.
